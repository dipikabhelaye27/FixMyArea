# Security Policy

## Supported Versions

FixMyArea is continuously deployed and maintained. Security patches are applied directly to the `main` branch and deployed to production.

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

---

## Reporting a Vulnerability

We prioritize platform security, data integrity, and privacy. If you discover a potential vulnerability in FixMyArea:

1. **Do not create a public issue** on GitHub.
2. Email your findings directly to the maintainers at `security@fixmyarea.gov` or via confidential repository vulnerability reporting on GitHub.
3. Include the following details in your report:
   * Description of the vulnerability and its potential impact.
   * Reproduction steps or proof of concept (PoC).
   * Proposed mitigation or fix, if identified.

We will acknowledge receipt within 48 hours and provide an estimated remediation timeline.
